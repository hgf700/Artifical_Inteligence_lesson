# Machine Learning Lessons

This course introduces core machine learning concepts, algorithms, and practical implementations using popular Python libraries and frameworks.

## L1 — Data Pipelines and Basic Models
- Creating machine learning pipelines
- Loading and preprocessing datasets
- Feature selection and transformation
- Training Support Vector Machine (SVM) classifiers
- Linear regression models

## L2 — Ensemble Methods and Tree-Based Models
- Introduction to ensemble learning
- Combining multiple models
- Decision trees and random forests
- Gradient boosting methods 
- XGBoost implementation
- Sampling techniques with `BaggingClassifier`
- Supervised learning approaches

## L3 — Unsupervised Learning and Dimensionality Reduction
- Clustering algorithms
- Principal Component Analysis (PCA)
- Reducing dataset dimensions
- Visualizing high-dimensional data

## L4 — Neural Networks and Deep Learning
- Gradient optimization methods
- Building and training simple neural networks with PyTorch and TensorFlow
- Convolutional Neural Networks (CNN)

## L5 — Natural Language Processing (NLP)
- Text preprocessing techniques
- Tokenization and vectorization
- Measuring text similarity and distance
- Training simple NLP models
- Solving basic natural language tasks

## L6 — Reinforcement Learning
- Introduction to reinforcement learning
- Q-Learning algorithm
- Training agents in Gymnasium environments
